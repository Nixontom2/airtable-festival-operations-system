# User Guide

## Creating an Event
1. Navigate to the Events table
2. Click "Add record"
3. Enter event details
4. Assign venue, artists, and manager
5. Set status to Planning or Confirmed

## Assigning Assets
1. Open the Assets table
2. Link assets to an event
3. Set return date
4. Status updates automatically via workflows

## Managing Tasks
1. Create tasks in the Tasks table
2. Assign staff and due dates
3. Track progress using task views
