# Forms & Integrations

## Airtable Forms
- Artist onboarding
- Asset requests
- Event proposals

Forms are connected directly to Airtable tables with validation rules.

## External Integrations
Supported integrations include:
- Fillout (advanced forms)
- Zapier / Make (workflow automation)
- Email platforms (SendGrid-ready)

Integrations are designed to maintain data integrity and minimise manual input.
