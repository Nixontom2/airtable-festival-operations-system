# Scripts Overview

## Why Scripting?
Some operational logic cannot be handled by Airtable automations alone. Scripts are used for:
- Bulk updates
- Governance rules
- Workload monitoring

## Scripts Included
- auto-event-code.js
- staff-workload-monitor.js
- bulk-status-updater.js

Each script is designed to be run manually from the Airtable Scripting Extension.
