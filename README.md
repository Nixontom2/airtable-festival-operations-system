# Automations

## Event Confirmation Notification
Trigger:
- When Event Status changes to "Confirmed"

Action:
- Send email to Event Manager notifying confirmation

Purpose:
- Ensure production and marketing teams are informed immediately

---

## Asset Return Reminder
Trigger:
- When Return Date is tomorrow

Action:
- Send reminder email to operations team

Purpose:
- Reduce asset loss and delays

---

## Task Assignment Notification
Trigger:
- When a new Task is created

Action:
- Notify assigned staff member via email

Purpose:
- Ensure accountability and task visibility
