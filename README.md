
# Architecture Overview

## Purpose
The Festival Operations Management System is designed to centralise and automate operational workflows for a large-scale arts festival. It replaces fragmented spreadsheets and manual coordination with a single, scalable Airtable platform.

## Design Principles
- Relational data modelling
- Minimal data duplication
- Automation-first workflows
- Non-technical user accessibility
- Clear ownership and accountability

## Core Data Flow
Event → Artists / Assets / Venue / Staff → Tasks → Dashboards

## Stakeholders
- Production Team
- Operations Team
- Marketing & Communications
- Festival Management

Each stakeholder interacts with the same data through role-specific views and dashboards.

## Scalability
The system is designed to:
- Support hundreds of events
- Handle multiple venues simultaneously
- Scale staff and asset allocation without restructuring
